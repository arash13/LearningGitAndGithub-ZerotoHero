# راهنمای تحویل تمرین‌ها

تمرین هر هفته بعد از تدریس کامل با نام `exercises/week-NN/` ایجاد می‌شود. **از امروز پاسخ‌های فرضی یا نمره ساختگی ثبت نکن.**

## نمونه ساختار یک تمرین

```text
exercises/
  week-01/
    report.md
    evidence.txt
```

در `report.md` بنویس: هدف، مراحل انجام، نتیجه، خطاها، دلیل انتخاب راهکار و چیزهایی که یاد گرفتی.

برای ارائه مدرک، در حد امکان به Commit، Pull Request یا Issue لینک بده. در هفته‌های اول می‌توانی خروجی کوتاه و غیرحساس دستورها را ثبت کنی.

در تمرین‌های تخریبی، فقط روی مخزن آزمایشی کار کن و نسخه پشتیبان داشته باش.
