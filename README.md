# یادگیری Git و GitHub از صفر تا سطح حرفه‌ای

> یک دوره عملی، فارسی و مبتنی بر مستندات رسمی برای Windows، همراه با تمرین، آزمون و سابقه پیشرفت.

این مخزن دفتر یادگیری عمومی من است. مسیر شامل **۷ فاز و ۲۸ هفته آموزشی** است. هر هفته یک درس، تمرین، آزمون و معیار قبولی دارد. زمان‌بندی پیشنهادی است؛ **معیار عبور، تسلط عملی است نه گذشت زمان**.

## قرارداد آموزش

- مبنا: **Windows + Git Bash**. در صورت نیاز PowerShell هم بررسی می‌شود.
- هر درس: توضیح ساده ← مثال قابل اجرا ← تمرین ← آزمون مفهومی و عملی ← بازخورد.
- حداقل نمره قبولی: **۸۵ از ۱۰۰**؛ کارهای پرخطر نیازمند تشخیص شرایط ایمن هستند.
- وضعیت هر هفته در [پرونده پیشرفت](progress/PROGRESS.md) ثبت می‌شود.
- سرفصل همه ۲۸ هفته از ابتدا مشخص است؛ متن درس‌ها با انجام واقعی و بازخورد تکمیل می‌شود.
- اطلاعات حساس مثل رمز، توکن، کلید خصوصی و اطلاعات شخصی نباید در مخزن عمومی قرار بگیرند.
