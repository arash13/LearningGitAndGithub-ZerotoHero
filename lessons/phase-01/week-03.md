# هفته 03 | Status، Log، Diff و Gitignore

**فاز:** 1 | **وضعیت:** طرح درس، آماده تکمیل تعاملی هنگام رسیدن به این هفته

## نتیجه مورد انتظار

تغییرات، تاریخچه و فایل‌های مستثناشده را تحلیل کنی.

## مدل ذهنی

Git بین تغییر ثبت‌شده، stageشده و هنوز stageنشده تفاوت قائل می‌شود. فایل gitignore برای موارد هنوز رهگیری‌نشده کاربرد دارد و فایل از قبل trackشده را خودکار خارج نمی‌کند.

## واژه‌ها و دستورهای کلیدی

- `git status -sb`
- `git diff`
- `git diff --staged`
- `git log --oneline --graph`
- `git show HEAD`
- `git add -p`

> هر دستور را قبل از اجرا از نظر پوشه فعلی، شاخه، تغییرات ثبت‌نشده و اثر بر Remote بررسی می‌کنیم. این فهرست، جایگزین آموزش عملی جلسه نیست.

## مثال و آزمایش هفته

**سناریو:** ۵ Commit قابل فهم بساز، یک فایل نمونه را ignore کن، و با diff توضیح بده کدام تغییر هنوز در Commit نیست.

گزارش باید شامل وضعیت اولیه، کار انجام‌شده، نتیجه قابل مشاهده، یک اشتباه و نحوه بررسی یا اصلاح آن باشد. نتیجه را با Link به Commit/PR/Issue یا خروجی سانسورشده ثابت کن.

## آزمون پایان هفته

1. چرا git diff ممکن است خالی باشد ولی git status تغییر نشان بدهد؟
2. gitignore چه اثری روی فایل قبلاً trackشده دارد؟
3. git add -p چه برتری نسبت به add همه فایل‌ها دارد؟

4. **آزمون عملی:** سناریو را با روش خودت کامل اجرا کن، وضعیت نهایی را ثابت کن و توضیح بده چرا این راهکار را انتخاب کردی.

## نکته ایمنی

فایل رمزدار واقعی نساز و آن را برای تمرین منتشر نکن.
