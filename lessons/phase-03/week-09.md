# هفته 09 | استانداردسازی مخزن و مستندات

**فاز:** 3 | **وضعیت:** طرح درس، آماده تکمیل تعاملی هنگام رسیدن به این هفته

## نتیجه مورد انتظار

یک مخزن قابل استفاده و قابل مشارکت بسازی.

## مدل ذهنی

README نقش دروازه ورود را دارد؛ License تعیین می‌کند دیگران تحت چه شرایطی می‌توانند استفاده کنند و CONTRIBUTING مسیر مشارکت را توضیح می‌دهد.

## واژه‌ها و دستورهای کلیدی

- `git status`
- `git add README.md`
- `git commit -m "docs: improve repository guide"`

> هر دستور را قبل از اجرا از نظر پوشه فعلی، شاخه، تغییرات ثبت‌نشده و اثر بر Remote بررسی می‌کنیم. این فهرست، جایگزین آموزش عملی جلسه نیست.

## مثال و آزمایش هفته

**سناریو:** README، نمونه استفاده، راهنمای مشارکت، راهنمای امنیت و قالب PR برای پروژه آزمایشی تهیه کن.

گزارش باید شامل وضعیت اولیه، کار انجام‌شده، نتیجه قابل مشاهده، یک اشتباه و نحوه بررسی یا اصلاح آن باشد. نتیجه را با Link به Commit/PR/Issue یا خروجی سانسورشده ثابت کن.

## آزمون پایان هفته

1. README خوب چه مشکلی را حل می‌کند؟
2. نبود License در مخزن عمومی چه پیامدی دارد؟
3. CODEOWNERS چه کاری می‌کند و به تنهایی چه تضمینی نمی‌دهد؟

4. **آزمون عملی:** سناریو را با روش خودت کامل اجرا کن، وضعیت نهایی را ثابت کن و توضیح بده چرا این راهکار را انتخاب کردی.

## نکته ایمنی

قوانین حقوقی License را پیش از انتخاب بفهم؛ به معنی Public بودن، مجوز استفاده آزاد نیست.
