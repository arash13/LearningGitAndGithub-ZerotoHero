# هفته 12 | CLI، Desktop، Codespaces، Search و امکانات مخزن

**فاز:** 3 | **وضعیت:** طرح درس، آماده تکمیل تعاملی هنگام رسیدن به این هفته

## نتیجه مورد انتظار

یک وظیفه را با چند ابزار انجام دهی و بهترین را انتخاب کنی.

## مدل ذهنی

رابط وب، GitHub CLI، Desktop و Codespaces مسیرهای متفاوت انجام عملیات‌اند. جست‌وجو، Watch، Notifications، Gists و Wiki ابزارهای پیرامونی مدیریت دانش‌اند.

## واژه‌ها و دستورهای کلیدی

- `gh --version`
- `gh auth status`
- `gh repo view`
- `gh pr status`
- `gh issue list`

> هر دستور را قبل از اجرا از نظر پوشه فعلی، شاخه، تغییرات ثبت‌نشده و اثر بر Remote بررسی می‌کنیم. این فهرست، جایگزین آموزش عملی جلسه نیست.

## مثال و آزمایش هفته

**سناریو:** یک Issue و یک PR آزمایشی را در وب و CLI بررسی کن؛ جست‌وجوی کد و اعلان‌های مرتبط را آزمایش کن.

گزارش باید شامل وضعیت اولیه، کار انجام‌شده، نتیجه قابل مشاهده، یک اشتباه و نحوه بررسی یا اصلاح آن باشد. نتیجه را با Link به Commit/PR/Issue یا خروجی سانسورشده ثابت کن.

## آزمون پایان هفته

1. چه زمانی CLI مناسب‌تر است؟
2. Codespaces چه تفاوتی با Clone روی Windows دارد؟
3. Watch و Star چه تفاوتی دارند؟

4. **آزمون عملی:** سناریو را با روش خودت کامل اجرا کن، وضعیت نهایی را ثابت کن و توضیح بده چرا این راهکار را انتخاب کردی.

## نکته ایمنی

برای ورود به CLI، از سازوکار رسمی احراز هویت استفاده کن و توکن را در خروجی منتشر نکن.
