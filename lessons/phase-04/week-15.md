# هفته 15 | Objects، HEAD، Refs و ساختمان داخلی Git

**فاز:** 4 | **وضعیت:** طرح درس برای تکمیل و تمرین هنگام رسیدن به این هفته

## هدف یادگیری

توضیح بده Commit، Tree، Blob و Tag object چه رابطه‌ای دارند.

## اصل مفهومی

Git محتوا و رابطه نسخه‌ها را در object database نگه می‌دارد؛ Branch نامی برای پیدا کردن Commit است و HEAD وضعیت فعلی را مشخص می‌کند. رابطه پدر و فرزندی Commitها یک گراف جهت‌دار بدون دور می‌سازد.

## دستورها و اصطلاحات نمونه

- `git cat-file -t HEAD`
- `git cat-file -p HEAD`
- `git rev-parse HEAD`
- `git ls-tree HEAD`
- `git show-ref`

**دقت:** بعضی دستورها `OWNER`، `REPO` و شناسه نمونه دارند و قبل از اجرا باید با مقدار واقعی جایگزین شوند. کار با ابزار پولی یا دسترسی سازمانی در صورت نبود مجوز با سناریوی شبیه‌سازی انجام می‌شود.

## آزمایش عملی

یک Commit نمونه بساز و با cat-file و ls-tree ساختمان و محتوای آن را بررسی کن؛ یک نمودار ساده از HEAD، branch، commit و tree بکش.

گزارش باید وضعیت اولیه، اقدامات انجام‌شده، شواهد نتیجه، اشتباه‌ها و منطق انتخاب راهکار را نشان بدهد.

## آزمون پایان هفته

1. آیا Branch تمام تاریخچه را کپی می‌کند؟
2. Blob و Tree چه تفاوتی دارند؟
3. Detached HEAD یعنی چه و چه خطری برای پیدا کردن Commitها دارد؟
4. **آزمون عملی و دفاع:** یک نمونه مستقل از سناریوی درس اجرا کن، مدرک ارائه بده و ریسک یا جایگزین راه‌حل را توضیح بده.

## ایمنی

برای فهم internals ابتدا از دستورهای فقط‌خواندنی استفاده کن.
