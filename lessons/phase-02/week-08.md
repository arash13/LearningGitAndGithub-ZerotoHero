# هفته 08 | Pull Request، Review و ادغام تغییرات

**فاز:** 2 | **وضعیت:** طرح درس، آماده تکمیل تعاملی هنگام رسیدن به این هفته

## نتیجه مورد انتظار

چرخه پیشنهاد، بررسی و ادغام تغییر را مستقل اجرا کنی.

## مدل ذهنی

Pull Request گفت‌وگو و بررسی روی اختلاف دو شاخه است. ادغام با Merge Commit، Squash یا Rebase اثرهای متفاوتی بر تاریخچه دارد.

## واژه‌ها و دستورهای کلیدی

- `git switch -c docs/example`
- `git push -u origin docs/example`
- `git log --oneline --graph --all`

> هر دستور را قبل از اجرا از نظر پوشه فعلی، شاخه، تغییرات ثبت‌نشده و اثر بر Remote بررسی می‌کنیم. این فهرست، جایگزین آموزش عملی جلسه نیست.

## مثال و آزمایش هفته

**سناریو:** یک PR با عنوان روشن، خلاصه تغییر، روش تست و بررسی اختلاف بساز؛ بعد از بازبینی، آن را ادغام کن.

گزارش باید شامل وضعیت اولیه، کار انجام‌شده، نتیجه قابل مشاهده، یک اشتباه و نحوه بررسی یا اصلاح آن باشد. نتیجه را با Link به Commit/PR/Issue یا خروجی سانسورشده ثابت کن.

## آزمون پایان هفته

1. چرا PR قبل از ادغام مفید است؟
2. Squash چه اثری روی Commitها دارد؟
3. Draft PR چه کاربردی دارد؟

4. **آزمون عملی:** سناریو را با روش خودت کامل اجرا کن، وضعیت نهایی را ثابت کن و توضیح بده چرا این راهکار را انتخاب کردی.

## نکته ایمنی

از ادغام مستقیم تغییرات بررسی‌نشده در شاخه اصلی پرهیز کن.
