# هفته 20 | CodeQL، Dependabot، Secret Scanning و Supply Chain

**فاز:** 5 | **وضعیت:** طرح درس برای تکمیل و تمرین هنگام رسیدن به این هفته

## هدف یادگیری

ریسک وابستگی و گردش انتشار را تشخیص و کاهش دهی.

## اصل مفهومی

Dependency Graph پایه شناسایی وابستگی‌هاست؛ Dependabot به‌روزرسانی و هشدار فراهم می‌کند؛ Code Scanning الگوهای آسیب‌پذیری و Secret Scanning افشای اعتبارنامه را بررسی می‌کند. پوشش قابلیت‌ها به پلن و نوع مخزن وابسته است.

## دستورها و اصطلاحات نمونه

- `gh api repos/OWNER/REPO/dependabot/alerts`
- `gh run list`

**دقت:** بعضی دستورها `OWNER`، `REPO` و شناسه نمونه دارند و قبل از اجرا باید با مقدار واقعی جایگزین شوند. کار با ابزار پولی یا دسترسی سازمانی در صورت نبود مجوز با سناریوی شبیه‌سازی انجام می‌شود.

## آزمایش عملی

روی یک پروژه آزمایشی با وابستگی کنترل‌شده، وضعیت هشدار را بررسی و برنامه اصلاح با اولویت ثبت کن. ساختن Secret واقعی برای تست ممنوع است.

گزارش باید وضعیت اولیه، اقدامات انجام‌شده، شواهد نتیجه، اشتباه‌ها و منطق انتخاب راهکار را نشان بدهد.

## آزمون پایان هفته

1. چرا به‌روزرسانی وابستگی بدون تست کافی نیست؟
2. SBOM چیست و چه کاربردی دارد؟
3. تفاوت Code Scanning و Secret Scanning چیست؟
4. **آزمون عملی و دفاع:** یک نمونه مستقل از سناریوی درس اجرا کن، مدرک ارائه بده و ریسک یا جایگزین راه‌حل را توضیح بده.

## ایمنی
