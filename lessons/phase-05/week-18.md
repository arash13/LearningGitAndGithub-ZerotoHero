# هفته 18 | Actions پیشرفته، Cache، Matrix، OIDC و Security

**فاز:** 5 | **وضعیت:** طرح درس برای تکمیل و تمرین هنگام رسیدن به این هفته

## هدف یادگیری

Workflow چندمرحله‌ای امن با کنترل هم‌زمانی و مجوز بسازی.

## اصل مفهومی

Matrix مجموعه ترکیب‌های تست را اجرا می‌کند؛ Cache زمان اجرای وابستگی‌ها را کم می‌کند؛ Artifact نتیجه قابل دانلود تولید می‌کند؛ OIDC می‌تواند اعتماد کوتاه‌مدت بدون Secret بلندمدت فراهم کند.

## دستورها و اصطلاحات نمونه

- `gh run list --limit 5`
- `gh run view RUN_ID --log`
- `gh workflow list`

**دقت:** بعضی دستورها `OWNER`، `REPO` و شناسه نمونه دارند و قبل از اجرا باید با مقدار واقعی جایگزین شوند. کار با ابزار پولی یا دسترسی سازمانی در صورت نبود مجوز با سناریوی شبیه‌سازی انجام می‌شود.

## آزمایش عملی

دو Job آزمایشی برای تست و گزارش ایجاد کن؛ مجوز token را روی حداقل مورد نیاز قرار بده و concurrency را توضیح بده.

گزارش باید وضعیت اولیه، اقدامات انجام‌شده، شواهد نتیجه، اشتباه‌ها و منطق انتخاب راهکار را نشان بدهد.

## آزمون پایان هفته

1. Cache و Artifact چه تفاوتی دارند؟
2. چرا pin کردن Actionهای شخص ثالث اهمیت دارد؟
3. OIDC نسبت به Secret بلندمدت چه مزیتی دارد؟
4. **آزمون عملی و دفاع:** یک نمونه مستقل از سناریوی درس اجرا کن، مدرک ارائه بده و ریسک یا جایگزین راه‌حل را توضیح بده.

## ایمنی

Secret را حتی برای عیب‌یابی داخل logs چاپ نکن؛ مراقب دسترسی Workflowهای PR از Fork باش.
