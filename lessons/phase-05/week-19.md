# هفته 19 | Release، Tag، SemVer، Pages و Packages

**فاز:** 5 | **وضعیت:** طرح درس برای تکمیل و تمرین هنگام رسیدن به این هفته

## هدف یادگیری

یک نسخه قابل ارجاع و بازتولید منتشر کنی.

## اصل مفهومی

Tag به نسخه مشخص اشاره می‌کند؛ Release در GitHub اطلاعات انتشار را اضافه می‌کند؛ SemVer از قالب MAJOR.MINOR.PATCH برای بیان نوع تغییر استفاده می‌کند.

## دستورها و اصطلاحات نمونه

- `git tag -a v1.0.0 -m "first release"`
- `git tag --list`
- `git push origin v1.0.0`
- `gh release list`

**دقت:** بعضی دستورها `OWNER`، `REPO` و شناسه نمونه دارند و قبل از اجرا باید با مقدار واقعی جایگزین شوند. کار با ابزار پولی یا دسترسی سازمانی در صورت نبود مجوز با سناریوی شبیه‌سازی انجام می‌شود.

## آزمایش عملی

برای پروژه تمرینی یک نسخه v1.0.0 ثبت کن، Release Notes بنویس و یک صفحه مستندات آزمایشی منتشر کن.

گزارش باید وضعیت اولیه، اقدامات انجام‌شده، شواهد نتیجه، اشتباه‌ها و منطق انتخاب راهکار را نشان بدهد.

## آزمون پایان هفته

1. Tag با Branch چه فرق دارد؟
2. افزایش MAJOR چه معنی قراردادی دارد؟
3. Release قابل بازتولید چه مشخصاتی دارد؟
4. **آزمون عملی و دفاع:** یک نمونه مستقل از سناریوی درس اجرا کن، مدرک ارائه بده و ریسک یا جایگزین راه‌حل را توضیح بده.

## ایمنی

پیش از انتشار عمومی، محتوا، فایل‌های ناخواسته و جزئیات امنیتی را بررسی کن.
