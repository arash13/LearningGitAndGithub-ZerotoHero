# شیوه آزمون و قبول شدن

هر هفته ۳ نوع سؤال دارد:

۱. **مفهومی:** «چرا این دستور؟» یا تفاوت دو مفهوم نزدیک.
۲. **پیش‌بینی و تشخیص:** خروجی محتمل `status`، `log` یا خطای اجرای دستور را توضیح بده.
۳. **عملی:** در مخزن تمرینی کاری انجام بده و نتیجه را با مدرک ارائه کن.

## نمره‌دهی

| محور | سهم |
|---|---:|
| درک مفهومی | ۲۵ |
| اجرای عملی | ۲۵ |
| حل مسئله | ۳۵ |
| توضیح منطق تصمیم | ۱۵ |

قبولی از ۸۵ شروع می‌شود. اشتباه امنیتی جدی مانند انتشار توکن یا حذف غیرقابل‌بازیابی داده در پروژه واقعی، تا اصلاح فهم و بازآزمون، مانع قبولی است.

سؤالات انتهای فایل هر هفته **بدون پاسخ‌نامه** هستند تا بتوان از آن‌ها برای ارزیابی استفاده کرد. مربی بعد از تحویل پاسخ، بازخورد و تمرین اصلاحی می‌دهد. نمره و مدرک در [PROGRESS](../progress/PROGRESS.md) ثبت می‌شود.
